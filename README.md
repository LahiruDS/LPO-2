# ⚖️ Jayasekara Legal Associates

A modern and responsive legal services website developed for **Jayasekara Legal Associates** using **React**, **Vite**, and **CSS**. The website showcases the firm's legal services, professional team, contact information, and provides an online consultation request form integrated with **EmailJS**.

---

## 🌐 Features

- 🏛️ Modern and professional legal website design
- 📱 Fully responsive across all devices
- ⚡ Built with React + Vite for fast performance
- 📄 Services section
- 👨‍⚖️ About the firm
- 💼 Practice areas
- 📞 Contact information
- 🗺️ Google Maps integration
- 💬 WhatsApp direct chat
- 📧 EmailJS-powered consultation request form
- 🎨 Clean UI with smooth animations

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/jayasekara-legal-associates.git
```

### Navigate to the project

```bash
cd jayasekara-legal-associates
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```
